# ❤️ Spider-Man Movie Date Website

A premium interactive romantic website inspired by Marvel aesthetics, created as a fun and memorable invitation for a Spider-Man movie date.

## ✨ Features

- 💜 Premium Purple & Pink Love Theme
- 🕷️ Spider-Man Inspired UI
- 💖 Floating Hearts & Particle Effects
- 🎬 Interactive 5-Step Story Experience
- 🐰 Cute Animated Rabbit
- ✨ Smooth Page Transitions
- 🎭 Glassmorphism Design
- ❤️ Typewriter Animations
- 📱 Fully Responsive (Mobile & Desktop)
- 🎉 Confetti & Celebration Effects

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- GSAP Animations
- Responsive Design

## 📂 Project Purpose

This project was created as a creative way to invite someone on a movie date through an interactive storytelling experience. It focuses on beautiful UI, smooth animations, and a cinematic user experience.
